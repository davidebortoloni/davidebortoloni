# Ciao, sono Davide 👋

Sviluppatore **full stack freelance** a Torino, con partita IVA dal 2024.
Progetto e sviluppo applicazioni web complete, dal database all'interfaccia, con **Laravel**, **Vue** e **Inertia**.

Il punto di partenza è sempre lo stesso: capire come lavorano le persone, poi scrivere codice.
Ogni funzione deve avere uno scopo preciso: migliorare un processo o semplificare il lavoro di qualcuno.

<br clear="right">

## Cosa faccio

- **Applicazioni web su misura**: dall'analisi del processo al rilascio, e dopo.
- **Gestionali** che tolgono lavoro ripetitivo a chi li usa ogni giorno.
- **Prodotti digitali**, dall'idea alla versione online e poi nel tempo.
